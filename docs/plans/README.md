# Historical plans and investigations

[Documentation](../README.md)

These dated documents record proposals, implementation steps, and investigations at the
time they were written. They are not current setup or release instructions, and the
presence of a plan does not mean its work shipped. Some include old branch rules, paths,
device support assumptions, or bench-specific commands.

For current operations, use [Installation](../installation.md),
[Maintenance](../maintenance.md), [Development](../development.md), and
[Releases](../releases.md). Keep plans as historical context; record new verification
evidence in [Reports](../reports/README.md).
