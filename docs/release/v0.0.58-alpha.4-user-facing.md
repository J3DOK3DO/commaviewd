StarPilot alpha testing now works on a normally installed StarPilot, paired with CommaView Android 0.0.162-alpha.5. Includes everything in v0.0.58-alpha.3.

- Recognizes StarPilot as its installer sets it up (by the repository's former name, `firestar5683/openpilot`), in any letter case. Earlier alphas stopped with "unsupported upstream remote" on a StarPilot installed from `installer.comma.ai/firestar5683/StarPilot`.
- Recordings, drive stats and storage estimates find drives saved with StarPilot's High Bitrate Recording or Konik settings, which keep drives in their own folder.
- Follows whichever encoder queue StarPilot opened most recently, so a leftover queue can't hold video back.
- Stops sending a driving-mode label StarPilot never shows; StarPilot's modes come through as its own border and path colors.

Testing notes: on a comma 3X and a comma four installed from StarPilot's installer, update the app to 0.0.162-alpha.5 and install the runtime from it. Turn off StarPilot **Disable Logging** so video can stream. Check Live View with StarPilot's Camera View set to Standard, Wide, Driver and None. With High Bitrate Recording on, check new drives appear in Recordings and export.

This is an alpha for device validation. The public beta remains unchanged.
