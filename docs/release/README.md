# Per-tag release notes

[Documentation](../README.md) · [Release procedure](../releases.md) · [What's new](https://commaview.com/whats-new)

The release workflow uses `<tag>-user-facing.md` as the GitHub release body when a file
matches the exact tag being published. Numbered alpha tags need their full suffix in the
filename. Otherwise the workflow generates a generic body.

These are historical notes for their named tags, not a list of all published runtimes or
the public installer's current default.
