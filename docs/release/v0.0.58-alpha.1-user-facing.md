StarPilot support is now available for alpha testing on comma 3X and comma four, paired with CommaView Android 0.0.162-alpha.1.

- Recognizes the StarPilot fork and exports its driving modes, status colors, custom path settings, and selected camera.
- Supports both older road/driver encoder queue names and newer narrowRoad/cabin names without taking a queue reader slot.
- Works with the matching Android StarPilot HUD in Live View and saved replay exports.

Testing notes: turn off StarPilot **Disable Logging** to allow its video encoder to run. Update both the Android app and comma runtime, then complete any requested reboot while parked or offroad.

This is an alpha for device validation. Check HEVC playback, road/wide/driver/none switching, driver mirroring and crop on comma 3X/four, and live versus recorded overlays. Optional StarPilot dashboard widgets and downloadable themes are not fully mirrored. The public beta remains unchanged.
